Documentation

Language guide.

Welcome to Aether. To start developing, ensure you have the 'ae' compiler installed. You can verify your installation by running 'ae version'. A typical Aether project starts with an entry point function named 'main'.
Everything in Aether is an actor. Actors are autonomous units of computation that communicate via asynchronous message passing. This isolation ensures that state is never shared, eliminating a whole class of concurrency bugs.
Aether features a powerful Hindley-Milner based type system. In most cases, you don't need to specify types; the compiler will infer them for you while still maintaining full static type safety.
The Aether standard library (std) provides high-level modules for I/O, networking, collections, and concurrency primitives. For example, 'std.io' handles printing and terminal interactions.
