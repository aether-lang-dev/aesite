A compiled actor language

Clear code that compiles to C.

Aether has actors, type inference, and pattern matching, then lowers to readable C a normal compiler builds. Native speed, no VM, no garbage collector.

counter.ae
message Inc { n: int }

actor Counter {
    state count = 0

    receive {
        Inc(n) -> {
            count = count + n
            println("count = ${count}")
        }
    }
}

main() {
    c = spawn(Counter())
    c ! Inc { n: 41 }   // count = 41
    c ! Inc { n: 1 }    // count = 42
}

What it is

/> c

Compiles to C

Readable C output, native speed, and direct use of any C library. No opaque runtime underneath.

/> actors

Actors, not locks

Typed message passing scheduled across every core. No shared mutable state, nothing to lock.

/> mem

No GC, no VM

Deterministic memory with defer and compiler-inserted ownership tracking. Nothing collects behind you.

/> ship

Tiny & portable

Static binaries in the hundreds of KB, cross-compiled to Linux, macOS, Windows and BSD from one host.

The output is the point

You can read what it produces.

Every program lowers to C a person can audit, then a normal compiler builds it. No bytecode, no black box.
