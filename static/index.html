Actor-based concurrency with automatic multi-core scheduling

Type inference with optional annotations lets you write code without defining, but does not prevent you from...

Aether compiles to C for portability, native performance and seamless C interoperability.

Multi-core partitioned scheduler with locality-aware actor placement

Actors placed on the caller's core for efficient parent-child messaging

Communicating actors automatically converge onto the same core

Work-stealing fallback for idle core balancing

Lock-free SPSC queues for same-core messaging

Cross-core messaging with lock-free mailboxes

Use defer for cleanup. All allocations cleaned up explicitly.

Arena allocators for actor lifetimes

Memory pools with thread-local allocation

Actor pooling reducing allocation overhead

Zero-copy message delivery in single-actor main-thread mode (caller stack passed directly)

SIMD batch processing with AVX2 support

NUMA-aware allocation for multi-socket systems

CPU feature detection for runtime optimization selection

Performance profiling with per-core cycle counting

Message tracing for debugging

Get started

      
Easy installation.


      

        
        
      


      

        

          
1 — Install

          

            git clone https://github.com/nicolasmd87/aether.git
            
          

        

        

          
2 — Verify

          

            ae version list
            
          

        

        

          
3 — Run your first program

          

            cd aether && ./install.sh
            
          

        

        
Supports macOS 12+ and most Linux distributions. Requires no additional dependencies — a single binary.

      


      

        

          
1 — Download

          

            Download aether-*-windows-x86_64.zip from Releases
          

        

        

          
2 — Extract

          

            Extract to any folder (e.g. C:\aether)
          

        

        

          
3 — Add to PATH

          

            Add C:\aether\bin to your PATH
            
          

        

        

          
4 — Restart terminal

          

            Restart your terminal (so PATH takes effect)
          

        

        

          
5 — Run your first program

          

            ae init hello && cd hello && ae run
            
          

        

        
Supports Windows 11 and later. No dependencies required.
