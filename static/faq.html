Common questions.

Aether focuses on extreme clarity and high-level actor abstractions. While Rust emphasizes memory safety through ownership and Go through simplicity/goroutines, Aether provides a built-in actor model with location-aware scheduling, making distributed and concurrent systems feel like writing single-threaded code.
Aether is currently in Beta (v0.25.0). While the core runtime is stable and used in several internal projects, the ecosystem is still growing. We recommend it for microservices, tooling, and performance-critical components.
Aether uses a hybrid approach: local actor memory is managed via high-performance arena allocators, while long-lived shared data uses explicit manual management with 'defer' blocks. This eliminates the "stop-the-world" latency of traditional garbage collection.
Yes. Aether compiles to C and has been designed with seamless FFI (Foreign Function Interface) in mind. You can import C headers directly and call native functions with zero overhead.
Aether currently supports macOS (Intel/M-series), Linux (x86_64/ARM64), and Windows 11. Since it compiles to standard C99, it can be ported to almost any platform with a C compiler.
